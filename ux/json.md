# JSON Collection: контракт интеграции

Памятка описывает формат ответа внешнего сервиса для источника типа `json_collection`.

## HTTP-запрос

Channelbot выполняет запрос:

```http
GET {endpoint_url}?hours=24&limit=100
Accept: application/json
Authorization: {настроенное значение, если задано}
```

Требования:

- Endpoint должен быть публичным `HTTPS`-адресом без встроенных credentials.
- HTTP-редиректы запрещены.
- Ответ должен иметь статус `2xx`.
- Рекомендуемый `Content-Type` — `application/json`.
- `hours` задаёт глубину выборки в часах.
- `limit` задаёт максимальное количество подборок и находится в диапазоне от `1` до `100`.

## Полный пример ответа

```json
{
  "status": "success",
  "collections": [
    {
      "collection_id": "movies-2026-08-04",
      "title": "Фильмы на вечер",
      "created_at": "2026-08-04T18:30:00+03:00",
      "items": [
        {
          "work_id": "bc5c0d27-8488-4725-8acf-e4b38368602f",
          "title": "ВАЛЛ·И",
          "text": "Описание фильма.",
          "image_url": "https://cdn.example.com/posters/wall-e.jpg",
          "url": "https://example.com/movies/wall-e",
          "year": 2008,
          "external_ids": {
            "kinopoisk": "279102",
            "tmdb": "10681",
            "imdb": "tt0910970"
          },
          "rating": {
            "value": 8.4,
            "scale": 10,
            "source": "kinopoisk",
            "votes": 741392
          },
          "ratings": [
            {
              "value": 8.4,
              "scale": 10,
              "source": "kinopoisk",
              "votes": 741392
            }
          ],
          "posted": "2026-08-04T12:00:00+03:00",
          "duration_minutes": 98,
          "duration_scope": "total"
        }
      ]
    }
  ]
}
```

## Верхний уровень

| Поле | Тип | Обязательное | Правила |
| --- | --- | --- | --- |
| `status` | string | да | Только точное значение `success` |
| `collections` | array | да | Массив подборок, может быть пустым |

Невалидный верхний уровень приводит к ошибке всей синхронизации.

## Подборка

| Поле | Тип | Обязательное | Правила |
| --- | --- | --- | --- |
| `collection_id` | string | да | Непустой стабильный идентификатор |
| `title` | string | да | Непустое название |
| `created_at` | string | да | Дата в ISO 8601; следует всегда передавать timezone |
| `items` | array | да | Должен содержать хотя бы один валидный элемент |

`collection_id` используется для идемпотентного обновления. При повторной выдаче того же идентификатора существующая подборка обновляется, а не создаётся заново.

Невалидная подборка пропускается. Подборка, в которой не осталось валидных элементов, также пропускается.

## Элемент `items`

### Обязательные поля

| Поле | Тип | Правила |
| --- | --- | --- |
| `title` | string | Непустое название |
| `text` или `description` | string | Непустое описание |

При наличии обоих полей приоритет имеет `text`. Элемент без названия или описания пропускается, но остальные элементы подборки продолжают обрабатываться.

### Идентификатор

Поддерживаемые ключи в порядке приоритета:

1. `work_id`
2. `id`
3. `guid`

Значение должно быть непустой строкой:

```json
{
  "work_id": "stable-item-id"
}
```

Если идентификатор отсутствует, Channelbot генерирует его автоматически. Внешнему сервису следует всегда передавать стабильный `work_id`, уникальный внутри подборки.

### Изображение

Поддерживаемые ключи в порядке приоритета:

1. `image_url`
2. `image`
3. `poster`
4. `cover_url`

Канонический вариант:

```json
{
  "image_url": "https://cdn.example.com/image.jpg"
}
```

Требования к изображению:

- Значение должно быть прямой непустой URL-строкой.
- Разрешён только публичный `HTTPS`.
- URL со встроенными логином или паролем запрещён.
- HTTP-редиректы запрещены.
- Ответ изображения должен иметь статус `2xx`.
- Максимальный размер изображения — `10 MiB`.
- Поддерживаются MIME-типы `image/jpeg`, `image/png` и `image/webp`.
- Поддерживается ответ с `Content-Encoding: aws-chunked`.

Все валидные изображения скачиваются и прикрепляются к исходному посту. При создании Telegram-публикации автоматически выбираются первые 10 изображений.

### Ссылка на материал

Поддерживаемые ключи в порядке приоритета:

1. `url`
2. `source_url`
3. `link`

```json
{
  "url": "https://example.com/content/item"
}
```

### Дата публикации элемента

Поддерживаемые ключи в порядке приоритета:

1. `posted`
2. `published_at`
3. `pub_date`

```json
{
  "posted": "2026-08-04T12:00:00+03:00"
}
```

Значение сохраняется строкой. Следует использовать ISO 8601 с часовым поясом.

### Рейтинг

```json
{
  "rating": {
    "value": 8.4,
    "scale": 10,
    "source": "kinopoisk",
    "votes": 741392
  }
}
```

Для валидного `rating` обязательны:

- `value` — число;
- `scale` — число;
- `source` — непустая строка.

`votes` — необязательное число. Невалидный `rating` не удаляет элемент, а преобразуется в `null`.

`ratings` — необязательный массив дополнительных рейтингов. Его содержимое сохраняется без дополнительной нормализации.

### Остальные необязательные поля

| Поле | Тип | Поведение |
| --- | --- | --- |
| `year` | number | Преобразуется в integer |
| `external_ids` | object или array | Сохраняется как передано |
| `ratings` | array | Сохраняется как передано |
| `duration_minutes` | number | Преобразуется в integer |
| `duration_scope` | string | Сохраняется как передано |

Неизвестные дополнительные поля не мешают импорту и сохраняются внутри исходного `raw_collection`.

## Минимально допустимый ответ

```json
{
  "status": "success",
  "collections": [
    {
      "collection_id": "news-123",
      "title": "Главное за день",
      "created_at": "2026-08-04T18:00:00+03:00",
      "items": [
        {
          "work_id": "article-456",
          "title": "Заголовок материала",
          "text": "Описание материала."
        }
      ]
    }
  ]
}
```

Изображения, рейтинги, ссылки, год и продолжительность необязательны.
